# AI Lead Hunter

Telegram-бот для поиска фриланс-заявок в публичных Telegram-каналах.

## Что умеет

- мониторит публичные Telegram-каналы через t.me/s/;
- фильтрует мусор, вакансии, копирайтинг и SMM;
- ищет заявки на Telegram-ботов, AI-агентов, парсеры, Python-скрипты, API, CRM и автоматизацию;
- присылает найденные заявки в Telegram;
- формирует готовый отклик;
- показывает отчёт после скана;
- позволяет управлять каналами через кнопки;
- сохраняет обратную связь: подходящая заявка, мусор, бан канала.

## Запуск

1. Создать файл .env:

BOT_TOKEN=токен_бота_от_BotFather
OWNER_ID=твой_telegram_id

2. Установить зависимости:

pip install -r requirements.txt

3. Запустить:

python main.py

## Важно

Файл .env нельзя загружать в GitHub.
